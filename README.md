
# 🐺 Magical Empire Voice

### Proximity Voice Chat for Path of Titans

Magical Empire Voice is an independently developed proximity-based voice chat prototype designed to make communication in Path of Titans more immersive.

The goal is to allow players to hear one another naturally based on the distance between their dinosaurs, creating a more realistic multiplayer experience.

## ✨ Features

- **Player Verification:** Links voice chat participants to their Path of Titans accounts through an in-game verification process.
- **Real-Time Location Tracking:** Retrieves player coordinates through the Path of Titans server API.
- **Distance-Based Audio:** Automatically adjusts voice volume based on how close players are to each other.
- **Voice Controls:** Includes microphone selection, mute, and deafen functionality.
- **Multiplayer Support:** Allows verified players on separate devices to communicate using real-time voice connections.

## ✅ Development Progress

The prototype has been successfully tested with two players on separate computers.

During testing, players could hear each other at close distances, gradually became quieter as their dinosaurs moved apart, and became inaudible beyond the configured proximity range.

The system also successfully tracked player movement in real time.

**Current status:** Working PC/browser prototype. Further development and testing are ongoing.

## 🛠️ Technologies Used

- HTML, CSS, and JavaScript
- Node.js and Express
- LiveKit for real-time voice communication
- Path of Titans server API
- Cloudflare Tunnel for remote testing
